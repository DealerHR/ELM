# Candidate Assessment Workflow Guide

## Overview

The ELM Platform includes a comprehensive candidate assessment system that allows recruiters to send assessments to candidates via email links. Candidates can complete assessments without logging into the platform.

---

## How It Works

### 1. Assessment Creation (HR/Admin)

1. Navigate to **Assessments** page
2. Click "Create Template"
3. Fill in details:
   - Title (e.g., "Software Engineer Technical Assessment")
   - Description
   - Type (personality, knowledge, aptitude, technical)
   - Duration (minutes)
   - Passing score
4. Add questions to the assessment
5. Save the template

### 2. Candidate Addition (HR)

1. Navigate to **Candidates** page
2. Click "Add Candidate"
3. Enter candidate details:
   - Full name
   - Email address (required for invitations)
   - Phone
   - Applied position
   - Source
4. Save the candidate

### 3. Send Assessment Invitation (HR/Admin)

**From the Candidates view:**

1. Find the candidate in the list
2. Click the "Send Assessment" button
3. Select an assessment template from the dropdown
4. Click "Send Invitation"

**What happens behind the scenes:**

```typescript
// Create assessment invitation
const { data } = await supabase
  .from('candidate_assessments')
  .insert([{
    candidate_id: candidate.id,
    template_id: selectedAssessment.id,
    assigned_by: userProfile.id,
    status: 'assigned',
    expires_at: new Date(Date.now() + 7 * 24 * 60 * 60 * 1000), // 7 days
    invitation_token: // Auto-generated by database
  }])
  .select()
  .single();

// Generate invitation link
const invitationLink = `${window.location.origin}/assessment/${data.invitation_token}`;
```

### 4. Email Sent to Candidate

**Email Template:**

```
Subject: Assessment Invitation - [Company Name]

Dear [Candidate Name],

You have been invited to complete an assessment for the [Position] role at [Company Name].

Assessment: [Assessment Title]
Duration: [X] minutes
Expires: [Expiry Date]

Click the link below to start your assessment:
[Assessment Link]

This link will expire in 7 days.

Best regards,
[Company Name] Recruitment Team
```

**Note:** Currently, the system generates the invitation link. You'll need to send the email manually or integrate with an email service (SendGrid, AWS SES, etc.).

### 5. Candidate Takes Assessment

1. Candidate clicks the link in their email
2. Browser opens: `/assessment/[unique-token]`
3. Candidate sees assessment details and clicks "Start Assessment"
4. Questions are displayed one at a time
5. Candidate answers all questions
6. Candidate clicks "Submit Assessment"
7. Score is automatically calculated and saved
8. Candidate sees completion message

**Public Assessment Interface:**
- No login required
- Token-based authentication
- Time-limited access (default: 7 days)
- Secure, one-time use
- Mobile responsive

### 6. View Results (HR/Admin)

1. Navigate to **Candidates** page
2. Click on candidate name to view details
3. See assessment results:
   - Score and percentage
   - Completion time
   - Individual answers (if configured)
   - Pass/fail status

## Database Structure

### Tables Involved

**candidate_assessments**
- Stores invitation and results
- Fields: `invitation_token`, `expires_at`, `status`, `score`
- RLS policies allow public access with valid token

**assessment_templates**
- Stores assessment definitions
- Fields: `title`, `type`, `duration_minutes`, `passing_score`

**assessment_questions**
- Stores questions for each template
- Fields: `question_text`, `options`, `correct_answer`, `points`

**candidate_assessment_answers**
- Stores candidate's answers
- Fields: `assessment_id`, `question_id`, `answer`, `is_correct`

## Security Features

### Token-Based Access
- 32-byte random tokens (256-bit security)
- URL-safe encoding
- Single-use (can't retake after completion)
- Time-limited (default 7 days)

### Row Level Security (RLS)
- Anonymous users can only:
  - View assessments with valid, non-expired tokens
  - Update their own assessment progress
  - Submit answers
- Cannot view other candidates' assessments
- Cannot modify questions or correct answers

### Status Flow
```
assigned → in_progress → completed
               ↓
            expired (if time runs out)
```

### Email Service Integration

**Option 1: SendGrid**
```typescript
import sgMail from '@sendgrid/mail';

async function sendAssessmentInvitation(candidate, assessmentLink) {
```

## Customization Options

### 1. Change Token Expiry
```sql
-- Default is 7 days, change to 14 days
ALTER TABLE candidate_assessments
ALTER COLUMN expires_at
SET DEFAULT (now() + interval '14 days');
```

### 2. Add Custom Assessment Types
```sql
-- Add new assessment type
ALTER TABLE assessment_templates
DROP CONSTRAINT IF EXISTS assessment_templates_type_check;

ALTER TABLE assessment_templates
ADD CONSTRAINT assessment_templates_type_check
CHECK (type IN ('personality', 'knowledge', 'aptitude', 'technical', 'behavioral', 'custom'));
```

### 3. Auto-Send Emails
Create a Supabase Edge Function or use database triggers to automatically send emails when assessments are assigned.

## FAQ

**Q: Can a candidate retake an assessment?**
A: No, by default. Once submitted, the status becomes 'completed' and cannot be changed. To allow retakes, you'd need to create a new invitation.

**Q: What happens if the token expires?**
A: The candidate cannot access the assessment. The status automatically becomes 'expired' and they'll see an error message.

**Q: Can we track when candidates start vs complete assessments?**
A: Yes! The system tracks `assigned_at`, `started_at`, and `completed_at` timestamps.

**Q: How do we prevent cheating?**
A: Current measures:
- Time limits
- Question randomization (can be added)
- One-attempt only
- Token expiry
Additional anti-cheating measures can be added (webcam proctoring, browser lockdown, etc.)

**Q: Can candidates save and resume later?**
A: Yes, the `in_progress` status allows them to resume. Their answers are saved as they go.

**Q: How do we handle candidates without email?**
A: Email is required for the current workflow. Alternative: Send assessment link via SMS or other channels.
